# DemoQA — тест-кейсы

Учебное тестирование [Practice Form](https://demoqa.com/automation-practice-form).
В приложенном списке Qase **9 тест-кейсов**. Номера доходят до DP-10 с пропуском DP-6; номер последнего кейса не равен их количеству.

| ID | Сценарий из исходного списка |
|---|---|
| DP-1 | Ввод корректной даты рождения |
| DP-2 | Приём даты 1899 года — наблюдение, требующее уточнения допустимого возраста |
| DP-3 | Корректные First name и Last name |
| DP-4 | Некорректные First name и Last name |
| DP-5 | Выбор пола Male |
| DP-7 | Отправка формы с валидным Mobile |
| DP-8 | Отправка формы с валидной Date of Birth |
| DP-9 | Отправка формы с выбранным Subjects |
| DP-10 | Отправка формы с невалидным Mobile |

Это снимки учебных работ, а не подтверждение актуального прогона внешнего сайта. Для нового прогона нужно фиксировать дату, версию браузера, данные и результат каждого сценария. Ограничения на имена и возраст нельзя считать требованиями без их согласования.

Более подробный пример выбора границ и классов эквивалентности: [тест-дизайн локального стенда](../manual/test-design.md).
