## Загрузка через GitHub Desktop

1. В GitHub Desktop выбери File → Clone repository → URL и адрес https://github.com/silindanil01-ops/qa-portfolio. Если репозиторий уже клонирован, открой его и выполни Fetch origin / Pull origin.
2. Создай новую ветку, например portfolio-update.
3. Скопируй содержимое папки repository из архива в корень клонированного репозитория. Перенеси также папку .github, .gitignore и docs/.nojekyll. В архиве находятся добавленные и изменённые файлы; существующие скриншоты и исходная коллекция остаются в репозитории.
4. В Changes проверь список правок. Выполни тесты по README. Сделай Commit и Publish branch / Push origin.
5. Через Preview Pull Request создай PR, проверь diff и результаты Actions. После проверки слей его в основную ветку.

Скриншоты из исходного GitHub не требуется заменять. При обновлении через сайт GitHub убедись, что скрытая .github/workflows/tests.yml тоже загружена. GitHub Desktop удобнее для полного набора файлов.

## Включение GitHub Pages

В репозитории открой Settings → Pages → Build and deployment. Выбери Deploy from a branch, ветку main и папку /docs, затем Save. После завершения публикации GitHub покажет адрес сайта. Ожидаемый адрес при этих настройках — https://silindanil01-ops.github.io/qa-portfolio/; до успешной публикации он не считается работающим.

На Pages размещается только статическая страница портфолио. Python-стенд запускается локально и не публикуется вместе с ней.

[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Резюме и отклики

Готовый документ под Ozon Job использует заявленный кандидатом уровень Middle QA и подтверждённые публичные работы. Добавь в него реальные работодатели, месяцы, мобильные сборки, длительность Python-автоматизации и личные результаты до отклика. Детали запроса — в ozon-job-fit.md.

Для ручной вакансии сначала показывай DemoQA, требования, дефекты и Postman. Для Python — после освоения кода показывай Reservation Lab и собственные расширения. Под Java/C# не переименовывай Python-проект: нужен соответствующий код и навыки.

В папке career таблица вакансий и задания на готовность. Телефон, английский, диплом и неподтверждённые места работы не добавлены.
