## Выбор основного направления

Python выбран потому, что он уже был указан в исходном README как направление развития. Такой выбор не означает соответствие всем вакансиям со скриншота. Для Java и C# потребуются отдельные работы и уверенное владение языком; простая замена слов в резюме этого не даёт.

МКБ ближе по набору ручных задач, Ozon Python — по стеку учебного стенда. Это оценка сходства требований, а не рекомендация считать себя подходящим middle: обе вакансии требуют опыт, которого исходный GitHub не подтверждает.

## Что указывать в резюме сейчас

Подтверждены учебные работы DemoQA, Qase/Jira/DevTools и Postman. Новые автотесты и SQL добавлены с помощью Codex и отдельно помечены как учебный материал. Их наличие ещё не подтверждает самостоятельное владение Python или SQL. Годы коммерческого QA, работодатели, английский, высшее образование и достижения не придуманы.
