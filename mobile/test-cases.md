# Тест-кейсы для условного приложения смен

Статус всех строк: **НЕ ВЫПОЛНЯЛОСЬ**. Для проверки потребуются реальная спецификация, тестовая сборка и аккаунты. Ожидания опираются на [учебные допущения](risks-and-criteria.md).

Общее условие: тестовый пользователь авторизован, есть доступная смена с одним свободным местом, время и часовой пояс записаны в тестовых данных. Используются только подготовленные тестовые аккаунты.

| ID | Приоритет | Шаги | Ожидаемый результат |
|---|---|---|---|
| MOB-01 | P0 | Открыть список, выбрать смену, подтвердить запись | Сервер подтвердил запись; статус одинаков в карточке и списке |
| MOB-02 | P0 | Дважды быстро нажать «Записаться» | Одна запись; кнопка блокируется до ответа |
| MOB-03 | P0 | Отключить сеть после отправки до получения ответа, затем восстановить | Приложение перепроверяет статус, не создаёт дубль |
| MOB-04 | P0 | На двух аккаунтах одновременно выбрать последнее место | Успех у одного, понятный отказ у второго; лимит не превышен |
| MOB-05 | P0 | Отправить заявку и сразу свернуть приложение на 30 сек, затем вернуться | Статус соответствует серверу, нет повторной отправки |
| MOB-06 | P1 | Открыть список без сети, затем восстановить её | Сообщение об отсутствии сети; после восстановления доступны актуальные данные |
| MOB-07 | P1 | Отказать в разрешении на уведомления и записаться | Запись доступна; приложение не уходит в цикл запросов разрешения |
| MOB-08 | P1 | Разрешить push, открыть ссылку на смену из уведомления | Открыта соответствующая смена; нет другой карточки |
| MOB-09 | P1 | Открыть deep link без авторизации, затем войти | После входа — правильная карточка с допустимым доступом |
| MOB-10 | P1 | Выйти из аккаунта A, войти под B, открыть историю/ссылку A | Чужие личные данные и запись недоступны |
| MOB-11 | P1 | Посмотреть смену у границы суток и в другом часовом поясе | Дата и время соответствуют согласованному часовому поясу |
| MOB-12 | P2 | Увеличить системный шрифт, открыть карточку и подтверждение | Кнопка и важные значения видны, текст не обрезан |
| MOB-13 | P2 | Пройти ключевые элементы с TalkBack/VoiceOver | Метки, порядок фокуса и действия понятны |
| MOB-14 | P1 | Прервать запрос блокировкой экрана и вернуть приложение | Экран отражает фактический результат и не зависает |

Для каждого запуска фиксировать Android/iOS, модель, версию ОС, номер сборки, канал сети, часовой пояс, ID смены, шаги, факт и ссылку на доказательство. Не считать кейс `passed` без сравнения с сервером там, где он указан источником истины.
