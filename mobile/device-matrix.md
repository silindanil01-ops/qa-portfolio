# Матрица мобильного прогона

Точные поддерживаемые версии ОС определяются продуктом. Номера версий ниже намеренно не подставлены: их нужно взять из реальной матрицы поддержки, а не угадать по вакансии.

| Слой | Android | iOS | Назначение |
|---|---|---|---|
| Основное устройство | Физический телефон на поддерживаемой версии | Физический iPhone на поддерживаемой версии | Push, связь, жизненный цикл, жесты |
| Предыдущая версия | Эмулятор или телефон на предыдущей поддерживаемой версии | Симулятор или телефон на предыдущей поддерживаемой версии | Регрессия ОС |
| Малый экран | Устройство или профиль с минимальной поддерживаемой шириной | Поддерживаемый компактный профиль | Области касания и обрезка текста |
| Крупный шрифт | Системный масштаб + TalkBack | Dynamic Type + VoiceOver | Читаемость и доступность |
| Сеть | Wi‑Fi, мобильная сеть, offline, потеря связи в запросе | Те же сценарии | Повтор и восстановление |
| Разрешения | Push отказ / разрешение / изменение после запуска | Те же сценарии | Не блокировать основной путь |
| Состояние приложения | Первый запуск, возврат из фона, блокировка, перезапуск | Те же сценарии | Синхронизация статуса |

Для P0 приоритет — реальные устройства обеих платформ и серверный источник истины. Эмулятор/симулятор ускоряет воспроизведение и границы, но не заменяет проверки аппаратных особенностей. До конкретной версии продукта этот план остаётся **не выполненным**.
