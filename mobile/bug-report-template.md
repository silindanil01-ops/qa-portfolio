# Шаблон дефекта мобильного приложения

**Короткий заголовок:** действие → фактическая проблема.

**Сборка и среда:** приложение / версия и build / Android либо iOS / модель / версия ОС / сеть / часовой пояс / разрешения / тестовый аккаунт без персональных данных.

**Предусловия:** состояние аккаунта, ID тестовой смены, количество мест, связь с сервером.

**Шаги воспроизведения:** нумерованные действия, включая момент потери сети или сворачивания.

**Ожидалось:** наблюдаемый критерий из согласованного требования и состояние на сервере.

**Получилось:** фактический текст, состояние UI, ответ API, запись в хранилище при наличии доступа.

**Частота:** число воспроизведений / число попыток. **Серьёзность и приоритет:** обосновать отдельно.

**Доказательства:** скриншот / видео, обезличенные сетевые запросы, logcat либо логи iOS, ID запроса и время. Перед публикацией удалить токены, контакты и персональные данные.

**Статус проверки:** не заполнять без фактического прогона. Этот файл — шаблон, не отчёт о найденном дефекте Ozon.
