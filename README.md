# QA Engineer Portfolio

Привет! Меня зовут Данил, я начинающий QA Engineer. Это моё портфолио с примерами тест-кейсов, баг-репортов и тестирования API.

## 🛠 Используемые инструменты

| Инструмент | Назначение |
|------------|------------|
| **Qase.io** | Тест-менеджмент: создание тест-кейсов и хранение дефектов |
| **Jira** | Баг-трекер: ведение задач и багов, работа со статусами |
| **Postman** | Тестирование API: запросы и автотесты на JavaScript |
| **DevTools** | Поиск ошибок в Console и анализ Network запросов |
| **Git / GitHub** | Версионирование, ведение портфолио |

## 📁 Структура портфолио

### [📝 test-cases/](./test-cases)
10 тест-кейсов на форму регистрации demoqa.com в Qase.io.
Покрытие: позитивные и негативные сценарии, применение классов эквивалентности и граничных значений.

### [🐛 bug-reports/](./bug-reports)
Реальные баг-репорты найденные в процессе тестирования demoqa.com.
Включают шаги воспроизведения, скриншоты, логи из консоли DevTools, severity и priority.

### [🌐 api-testing/](./api-testing)
Коллекция Postman из 5 запросов с автотестами на JavaScript.
Покрытие: GET, POST, DELETE, проверка статус-кодов, времени ответа и структуры JSON.

## 🎯 Что я умею

### Теория тестирования
- Виды тестирования: smoke, sanity, regression, exploratory
- Уровни тестирования: unit, integration, system, e2e
- Техники тест-дизайна: классы эквивалентности, граничные значения, негативное тестирование
- Жизненный цикл бага: статусы, переходы, роли в команде
- Разделение Severity и Priority с обоснованием

### Документация
- Написание структурированных тест-кейсов с предусловиями и ожидаемым результатом
- Оформление баг-репортов с шагами воспроизведения, окружением, доказательствами
- Различие между тест-планом, тест-кейсом и чек-листом

### Инструменты
- **Qase.io** — создание Test Suite, ведение тест-кейсов, оформление дефектов
- **Jira** — создание Issue, работа со статусами, JQL запросы, сохранение фильтров
- **Postman** — отправка REST запросов, написание автотестов с pm.test и pm.expect
- **DevTools** — поиск ошибок в Console, анализ запросов в Network

### REST API
- HTTP методы: GET, POST, PUT, PATCH, DELETE
- HTTP статус-коды: 2xx, 4xx, 5xx и понимание их значения
- Чтение и проверка структуры JSON
- Написание автоматических проверок на JavaScript
