# Bug Reports

В этой папке размещены баг-репорты найденные на сайте demoqa.com.

## Используемые инструменты
- [Jira](https://www.atlassian.com/software/jira) — основной баг-трекер
- [Qase.io](https://qase.io) — раздел Defects

## Найденные баги

### 1. Страница ломается с белым экраном при очистке поля Date of Birth
- **Severity:** Critical
- **Priority:** High
- **Type:** TypeError в Console
- **Платформа:** Chrome, demoqa.com

### 2. Кнопка Close не закрывает модальное окно
- **Severity:** Major  
- **Priority:** High
- **Type:** TypeError в Console
- **Платформа:** Chrome, demoqa.com

### 3. Поле Date of Birth принимает год 1860
- **Severity:** Major
- **Priority:** Medium
- **Type:** Отсутствует валидация
- **Платформа:** demoqa.com

## Скриншоты
Скриншоты багов и логи из консоли DevTools прикреплены отдельными файлами.
